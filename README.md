# RaceDay

## 🏃 Overview

RaceDay is a full-stack, cloud-aware sports event management platform designed specifically for the South African road running, walking, and cycling community.

The platform provides a centralized solution for managing sporting events, replacing traditional paper-based registration systems, spreadsheets, and disconnected communication channels. RaceDay enables Event Organisers to create and manage events, categories, registrations, and results, while allowing Participants to discover events, register online, track their performance, and receive real-time event updates.
