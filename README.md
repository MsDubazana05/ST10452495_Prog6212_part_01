# RaceDay

## 🏃 Overview

RaceDay is a full-stack, cloud-aware sports event management platform designed specifically for the South African road running, walking, and cycling community.

The platform provides a centralized solution for managing sporting events, replacing traditional paper-based registration systems, spreadsheets, and disconnected communication channels. RaceDay enables Event Organisers to create and manage events, categories, registrations, and results, while allowing Participants to discover events, register online, track their performance, and receive real-time event updates.

---

## 📌 Problem Statement

South Africa has a rich culture of road races, marathons, cycling tours, charity runs, and community sporting events. Despite the growing popularity of these events, many organisers still rely on manual processes that are inefficient, time-consuming, and prone to errors.

RaceDay aims to digitize and streamline event management by providing a modern web-based platform that improves event administration, participant engagement, and access to event information.

---

## 🎯 Project Goals

- Digitize event registration and management.
- Improve communication between organisers and participants.
- Provide centralized event and performance tracking.
- Enable real-time access to event information.
- Support modern software development practices using APIs, cloud technologies, and CI/CD pipelines.
